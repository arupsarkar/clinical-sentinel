# ADR 0001: Record architecture decisions

**Status:** Accepted · **Date:** 2026-07-16

## Context
This project is built incrementally with an explicit goal of avoiding
black boxes. Decisions made in conversation are lost; decisions made
in commits lack rationale.

## Decision
We record every significant architectural decision as a short,
numbered ADR in this directory: context, decision, consequences.

## Consequences
Slight documentation overhead per decision, in exchange for a repo
whose design rationale is fully reconstructible by any reader —
including future us.
